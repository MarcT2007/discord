# Discord Obrazec (Klon)

Odzivna in natančna kopija uporabniškega vmesnika Discord obrazca, ustvarjena s sodobnimi spletnimi tehnologijami. Projekt posnema čisto zasnovo, animacije in interaktivne elemente originalnih Discord obrazcev.

---

## 🚀 Funkcionalnosti

* **Avtentičen UI/UX:** Oblikovano v tesnem skladju z uradnim Discordovim grafičnim sistemom in temno temo.
* **Prilagodljiv dizajn:** Optimizirano tako za namizne kot za mobilne zaslone.
* **Preverjanje vnosov:** Povratne informacije v realnem času za vnosna polja (npr. oblika e-pošte, obvezna polja).
* **Interaktivni elementi:** Gladki prehodi, prilagojena stanja polj ob fokusu in interaktivni gumbi.

---

## 🛠️ Uporabljene tehnologije

* **Frontend:** HTML5, CSS3 / Tailwind CSS, JavaScript / React (prilagodi glede na svoje tehnologije)
* **Ikone:** FontAwesome / Lucide Icons
